# 抗柠系统计算器

这是一个可直接部署到 GitHub Pages 的静态网站，用来计算“抗柠系统”指标。

## 直接使用

双击 `index.html` 可以在本地浏览器打开。页面不需要后端，不会把数据上传到服务器。

## GitHub Pages 部署

1. 将本仓库推送到 GitHub。
2. 在仓库设置中打开 Pages。
3. 选择部署分支和根目录。
4. 打开生成的网址即可使用。

## 指标说明

- `K-` 表示抗值，代表痛苦、阻滞、身体负荷和认知占用。
- `N+` 表示柠值，代表愉悦、意义、舒展和可控性。
- `KN = N+ - K-`，负值偏抗，正值偏柠。

所有固定常数默认取概念模型建议区间的中间值，并可在页面的高级参数中调整。

## 功能

- 实时计算抗值、柠值和净抗柠值。
- 仪表盘显示当前抗柠状态。
- 可复制或下载单次记录。
- 可保存本地历史记录，并导出 CSV。
- 所有历史记录保存在当前浏览器的本地存储中。

## 隐私说明

本工具是纯静态网页，没有数据库和远程接口。历史记录只保存在使用者自己的浏览器里。清空浏览器数据或点击页面中的“清空历史”会删除这些记录。

## 文件结构

- `index.html`：页面结构。
- `styles.css`：界面样式。
- `script.js`：计算逻辑、仪表盘、历史记录和导出功能。
